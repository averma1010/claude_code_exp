People often ask me about my development setup. Here's what I use and why.

## Editor: VS Code

I use Visual Studio Code for most of my coding. It's become the standard for good reason—great extension ecosystem, excellent TypeScript support, and it just works.

### My Essential Extensions

- **Prettier**: Auto-formatting is non-negotiable
- **ESLint**: Catch errors before they become bugs
- **Tailwind CSS IntelliSense**: Makes working with Tailwind much faster
- **GitLens**: Better Git integration

## Terminal: iTerm2 + zsh

I spend a lot of time in the terminal. iTerm2 with zsh and Oh My Zsh gives me everything I need—split panes, search, and good customization.

## Version Control: Git + GitHub

Nothing fancy here. Git for version control, GitHub for hosting. I follow a simple workflow:
- Main branch is always deployable
- Feature branches for new work
- Pull requests for code review
- Squash and merge to keep history clean

## Deployment: Cloudflare Pages

Cloudflare Pages has become my go-to for static sites. Free, fast, and automatic deployments from GitHub. What's not to love?

## The Philosophy

My setup prioritizes simplicity and speed. I don't want to spend time configuring tools—I want to spend time building things.

That said, I'm always trying new tools. The development ecosystem moves fast, and there's always something better around the corner.
